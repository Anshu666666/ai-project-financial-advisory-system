## 🎨 UI Component Libraries
* **[ShadCN UI](https://ui.shadcn.com/) / [ShadCN UI Blocks](https://ui.shadcn.com/blocks):** Completely free, open-source ecosystem.
* **[Vengence UI](https://www.vengenceui.com/)**
* **[Animate UI](https://animate-ui.com/)** - **(IMPORTANT: [Accordion](https://animate-ui.com/docs/base/accordion))**
* **[UIverse](https://uiverse.io/)** - Massive, community-driven database of free copy-paste CSS/Tailwind elements. (See also: [Glassmorphism search](https://uiverse.io/elements?search=glass&t=tailwind))
* **[Lunar UI](https://lunarui.dev/components)** - **(IMPORTANT)**
* **[Aceternity UI](https://ui.aceternity.com/)**
* **[21st.dev](https://21st.dev/):** Design engineer marketplace dominated by free, copy-paste shadcn components.
* **[React Bits](https://www.reactbits.dev/):** Completely free collection of animated React components.
* **[Vue Bits](https://vue-bits.dev/):** Open-source library of animated, interactive UI components for Vue.js & Nuxt (official port of React Bits).
* **[Kokonut UI](https://kokonutui.com/):** Free and open-source Tailwind & Shadcn UI component library.
* **[LaunchUI](https://launchui.com/):** Offers an excellent, functional free tier of open-source landing page sections.
* **[Tailark](https://tailark.com/):** Free tier gives you full access to all open-source starter blocks.
* **[Blocks by MVP Subha](https://blocks.mvp-subha.me/):** Entire component block collection is 100% open-source and free.
* **[Flowbite](https://flowbite.com/):** Very generous core library that is fully open-source and free to use.
* **[Magic UI / Motion Primitives](https://magicui.design/):** Extensive selection of free, highly aesthetic motion components alongside premium templates.
* **[Sera UI](https://seraui.com/)**
* **[Componentry](https://componentry.dev/):** Collection of beautiful, animated React UI components built with Tailwind CSS and Framer Motion.
* **[Skiper UI](https://skiper-ui.com/):** Extension library of modern, animation-friendly UI components for shadcn/ui and Next.js.
* **[Cult UI](https://www.cult-ui.com/):** Open-source, accessible, and customizable copy-paste UI components designed for design engineers.
* **[Watermelon UI](https://ui.watermelon.sh/):** React component registry compatible with shadcn CLI supporting React 19 and Tailwind CSS v4.
* **[OriginKit](https://www.originkit.dev/):** Open-source library of animated UI components for Framer and React.

## ✨ Animation & Motion
* **[Anime.js](https://animejs.com/) / [Animista](https://animista.net/):** Totally free, open-source web animation engines.
* **[Transitions.dev](https://transitions.dev/)**
* **[TripleD](https://tripled.work/):** Free open-source motion components powered by Framer Motion.
* **[Jitter](https://jitter.video/)**
* **[CSSFX](https://cssfx.netlify.app/)**
* **[Swishy](https://www.swishy.ai/):** AI-powered motion design and animation platform for kinetic typography and motion graphics.

* **[Unicorn Studio](https://unicorn.studio/)**
* **[SVG to 3D (3DAI Studio)](https://www.3daistudio.com/svgTo3D)**
* **[CSS Buttons](https://cssbuttons.io/)** - 100% free web utilities. (See also: **Neumorphism Generator**)
* **[Neumorphism.io](https://neumorphism.io/#e0e0e0)**
* **[Glassmorphism Generator (Hype4)](https://hype4.academy/tools/glassmorphism-generator)**
* **[Gradienty](https://gradienty.codes/)** - Check out Animated Icons, Mesh, Text Gradient. ([Alternate Link](https://gradienty.codes/#google_vignette))
* **[Cool Shapes](https://coolshap.es/)**
* **[Hallmark](https://github.com/nutlope/hallmark):** Open-source design skill for AI agents (Cursor, Claude Code) to generate diverse, high-quality, anti-slop web layouts.
* **[Variant](https://variant.com/):** AI-powered layout generator that produces continuous UI design variations from a single prompt.
* **[FreeMockup.video](https://www.freemockup.video/):** Browser-based tool to create watermark-free 3D mockup videos of apps/websites.
* **[Artkit](https://artkit.cc/):** Web utilities for image, motion, and creative graphic design.
